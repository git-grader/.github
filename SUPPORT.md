# Support

## Where to ask

- **Usage questions / ideas** — open a
  [discussion](https://github.com/orgs/git-grader/discussions) if enabled,
  or an issue labelled `question` on the relevant repository
- **Bugs** — open an issue using the bug report template
- **Security problems** — never in public; see [SECURITY.md](SECURITY.md)

## Before you ask

1. Check the repository README and documentation
2. Search existing issues — your question may already be answered
3. Include versions, deployment method (docker compose / manual), logs, and
   the smallest reproduction you can manage

Maintainers are volunteers; response times vary. Clear, complete reports get
faster answers.
