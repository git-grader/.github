<h3 align="center">Push code. Capture proof. Grade safely.</h3>

<p align="center">
  GitGrader is an open-source, self-hostable grading platform for courses that
  accept programming assignments over Git.
</p>

---

## How it works

`push` → `capture` → `run` → `grade` → `review`

- **Git-native** — students submit through the workflow they already use
- **Auditable** — each accepted push becomes a durable, reviewable record
- **Isolated** — grading runs in controlled containers, not on the host
- **Self-hostable** — institutions retain operational and data control
